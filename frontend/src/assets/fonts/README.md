# Fonts for resume PDFs

These are embedded in the PDFs Onward makes (see `src/resume-pdf/fonts.ts`).
Both are free to use and redistribute under the SIL Open Font License; the
licences are next to this file.

- **Roboto** (regular, medium, and bold): body text, and the headings in Compact and Modern
- **Neuton** (regular): the name and section headings
